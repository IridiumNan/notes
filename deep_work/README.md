# Deep Work

> 书中的一些摘要可以查看 [original.md](./original.md)

这本 *Deep Work* 当中写了很多故事， 逻辑严密的论证和原创性的东西比较少， 但是它确实把 Deep Work 这件事情本身拉到生活的中心位置来.

首先先探讨一下 `Deep Work` 的概念以及相对应的 `Shallow Work` 的概念

书中是这样阐述的:

**Deep Work**: Professional activities performed in a state of distraction-free concentration that push your cognitive capabilities to their limit. These efforts create new value, improve your skill, and are hard to replicate.

**Shallow Work**: Noncognitively demanding, logistical-style tasks, often performed while distracted. These efforts tend to not create much new value in the world and are easy to replicate.

以上是这本书提到的基本概念， 但是我们这里的目的不是厘清整本书的脉络， 而是将这本书的相关内容进行进一步的探索和实践化， 我只会针对一些我认为有所启发的点进行说明和探索。

> 其实我认为这本书挺水的, 可以讨论的东西比较少

## 什么是 Deep Work

- 书中对于 `Work` 的分析依旧停留在非常直观的层面， 我觉得应该要考虑更加系统性地研究 `Work` 这个对象的方法, 进而能够给如何进行好的 Deep Work 带来更多的思路, 这也是我们进行整体性分析的基础

### 注意力高度相关

作者在书中提到的区别补充种类工作的方法

How long would it take (in mouths) to train a smart recent college graduate with no specialized training in my field to complete this task ?

我认为在分析的过程中意义不大, 很多时候我们没得选， 所以我们只好以一种更加合理和高效的方式完成工作， 而不是做这样的区分

我认为区别 Deep Work 和 Shallow Work 的核心价值就在于指导我们**资源的调度和分配**。 所以我提出了新的区分方法:

通过分析这项任务的**抗干扰能力**, 进而分析是否属于 Deep Work

例如你在工作的过程中同时跟别人聊天， 最终投入产出比产生了显著的恶化，那么这就应当属于 Deep Work 的范畴

第一种情况是你需要投入更多的资源来进行， 比如同时聊天之后你需要显著花更多的时间才能够完成这个任务

第二种情况则是结果变差， 投入差不多的时间资源， 但是最终的效果却显著变差，也就是说明这件事情本身跟注意力有着很强的关系

正如书中提到的一个公式

$P = T \times I$

Where

- $P$ is High-Quality Work Produced

- $T$ is Time Spent

- $I$ is Intensity of Focus

事实上， Deep Work 的这一点特征就是 laser-focus, 因而我们通过这个方法才可以真正找到这个工作本身跟**注意力资源投入**之间的关系

我们不难看出， 当你没有 AI 来来代替你思考的时候， 有很多属于 `Deep Work` 的任务, 所以解决 如何正确的进行 `Deep Work` 这个问题才是我们应该关注的重点.

但是需要注意， 一件事情会被你当成 Deep Work 只有你事先体验过高度的注意力集中并且获得了良好且可观的效果。

也就是说一个无法真正集中注意力的人是没有办法区别这两者的， 因为他确实没有采集到函数上的各个取值进而观察该任务和注意力之间的完整关系

### 输出

高质量的输出也是 Deep Work 的充分条件，对于现有信息的阅读， 整合， 重新阐述， 思考， 最终到组织， 都需要大量的认知资源。

在输出的过程中， 大脑必须将模糊的想法收束到一个可以具体地写到纸面上的状态， 而这个选择和收束可能性的过程， 就是认知工作的核心内容。

不同种类的认知工作之间的差别在于面临的可能性空间不同， 在写一本书或者解决一个数学问题的时候， 面临的可能性空间都是巨大的， 因而它们也经常被视作 Deep Work.

### 总结

我们这里对于不同的任务进行分类， 核心的价值在于 **使用时间管理之外的维度来获得更高的收益**

大多数人对于如何将事情做好， 往往只有投入更多的时间这一个答案， 但是 Deep Work 向我们强调了第二个维度: How Deep (也就是认知资源的集中程度)

在横向上， 这意味着 资源高度集中在某一项具体的活动之上而不是同时分散到各处

也就是书中反复强调的 `free-distraction`

在纵向上， 这意味着良好的时间连续性

时间的连续性使得工作记忆的切换变少， 也就减少了认知资源的消耗， 进而达到更加高效的资源利用

> 当然对于 multi-task 这种东西还有待探讨， 我认为它的实现有两种途径  
> 一种是 任务的资源分配已经不再显式依靠大脑而是转向小脑等区域  
> 另一种是大脑资源的高速轮换  
> 前者是可以实现 Deep Work 的(比如说通过写字或者打字来表达自己的想法, 就是一种半自动化的接管)  
> 后者则是我们应当避免的， 它与 Deep Work 背道而驰

书中所举的例子大多不是统计学上的，而是个例， 通过对杰出人士的深度工作习惯来说明 Deep Work 的价值和合理性

为什么会出现这种情况? 因为是否为 Deep Work 和 How deep 是非常模糊且难以分析的, 并没有一种非常成熟的研究方法

另外 Deep Work 带来的好处可能并没有那么立竿见影，或许很多场景下它都不会带来显著的收益

然而这种大量使用个例的方法的确会降低说服力。

如果在杰出的人士当中， Deep Worker 的分布比例和普通人群当中的分布比例相等， 那么也就没有办法很好地说明 Deep Work 和取得成功的正相关

它们的相关性不高甚至很差在统计学上是完全可能的

虽然没有非常明显的统计学证据， 但是从 体感 上来看， Deep Work 确实是更加适合我的方式

如果你也认为自己对于 Deep Work 有兴趣并且可以从中受益， 可以继续往下看

## 如何进行 Deep Work

### 隔离

上面已经提到了， How Deep 可以取决于时间的连续性和注意力的集中程度.

我们应当尽量避免连续地使用自己的意志力 (很早就有研究说明注意力是一项有限的资源， 在 Deep Work 书中也提到了这一点)

而使用一些隔离的机制来自动地进行资源的集中和保证时间的连续性

**隔离的核心在于通过 filter 将不同的信息分类到不同的区域**， 从视觉上直接减少无关信息的来源， 进而增加注意力的集中程度

举几个例子

- **减少桌面图标**

Windows 操作系统的大部分用户， 将大量的内容放置在 Desktop， 这当然便于快速拿到所需要的文件

但问题是这些视觉元素的存在会不断地消耗注意力资源

在这一点上, GNOME 桌面就做的很好， 原生的 GNOME (Debian, Fedora) 是完全不带有桌面图标的， 并且各种状态也都收到右上角的控制面板

它将视觉降噪做成了桌面体验的核心, 我认为自己目前良好的注意力也是从使用 GNOME 桌面以来逐渐培养的

Windows 也支持直接隐藏桌面的图标， 可以尝试一下， 毕竟这种损失非常可控的实验可以让我们找到更适合自己的工作方式

- **善用电脑的工作区机制**

电脑的工作区就是一种非常好的场景隔离的方式

现代的电脑桌面大多采用堆叠窗口, 大量的窗口层层堆叠在同一个桌面， 于是如何寻找需要的内容而不被无关的窗口打扰就变成了一个问题

而工作区的设计就是为了解决这个问题， Windows 和 使用 GNOME 桌面的 Linux 发行版都支持多个工作区 (macOS 我不太了解)

将不同的工作隔离的不同的地方， 甚至尽量在一个工作区内只放置一个窗口， 尽量做到 **单线程**, 也就是同一时间只关注一样东西

在实践的过程中， 你的操作系统的桌面设计也会带来很大的影响。

比如说 GNOME 桌面可以通过插件自己指定某个应用的窗口在启动的时候移动到某一个工作区， 进行切换也只需要进行一次拖拽， 在我看来也算方便

但是 Windows 切换工作区就比较繁琐，那么对于两者， 我们的使用方式就不同， Windows 下进行隔离的粒度要更粗， 比如说一个工作区放影音， 另一个是工作, 还有一个是社交

- **Internet Block**

在这本书当中提到: 过去有一种方法， 是偶尔进行网络截断进而使得人重新认识到因为网络而错过了什么。

事实证明这个方法并不好， 书中提出另外一种方案， 在现在看来是极其激进的: 根据需要分配可以上网的时间块.

它将人的心理状态翻转过来， 把默认的模式设置为断网模式， 而网络的使用被当成一种 资源在进行调度。

上网不再成为一种理所当然， 而是我需要 xxx, 所以我要上网, 那么我会分配 xx~xx 这段上网时间。

它让我们重新思考上网的价值, 这种观念相信我们的注意力和精力比一堆不知道有没有用的网上信息更加珍贵。

对于现在大多数的人来说， 这都是极其不可思议的思路, 但是它并非不可行

原因如下: 即使在工作阶段你需要进行持续的上网， 那么你也不应该将上网视作一种理所当然的事情。

现在的人每天上网的时间就略小于清醒时间 (至少我周围的人基本如此)

但是事实上我们不需要那么多的上网时间， 分析每一次真正的上网需求并进行时间块的分配。

会降低我们上网的时间和频率，核心的矛盾依旧在于， 大多数的网络服务就是围绕上瘾打造的， 如果你还珍视自己的时间和精力资源， 或许你应该尝试这种方案

### 良好的输出

对于某些本身没有设置任何明确产出的任务， 大多数人的态度都是做了就行

但是由于一直处于输入的状态， 而这种状态对大脑的认知资源的调度也不算过于强制

所以是否能够真正集中注意力以及真正的理解， 很大程度上取决于你是否对这些信息感兴趣

这个时候我们需要人为引入一些机制来收束注意力资源

最好的方法我认为就是进行输出

也就是对于看到的信息进行筛选(比如说做一些摘要)， 甄别比较(问一些问题), 再次阐述和总结

为了输出， 我们必须进行不同信息的识别和重新组合， 就可以有效的收束自己的注意力
