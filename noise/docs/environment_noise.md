# 情景噪声

对于情景噪声， 我提出自己的一点观点， 我也不认为我的观点可以通过实验进行验证， 因为它是一种纯粹的猜想，然而人类的思想和大脑本身就是一个近乎无法拆解的黑盒，所以我这里只是提供一个可能的机制猜想。

对于一些不应该影响专业判断的因素真实地影响专家的判断决策的现象， 比如说天气， 当地球队的在昨天获得了胜利这些看似不应该影响最终的决策的因素被证明与最终的结果具有相关性。
首先我认为我们如果对这些事情感到惊讶，就代表我们一直认为人类是一种绝对理性的存在， 但卡尼曼的 《思考快与慢》早就区分了人类的系统一和系统二。其中绝大多数的日常判断都基于系统一，但是说到专业判断， 尽管我们会尽力减少无关因素， 但是人类并没有办法真实地做到完全屏蔽系统一的影响。

而我认为之所以一些无关的情景输入（视觉， 听觉等）会影响人类的最终决策，是因为人类的大脑神经结构本身就**并非是各个区域都正交运行**的，这是相互影响的基础， 另外一方面就是我们低估了情绪以及想象力对于判断的影响力， 即使我们没有意识到那些本来无关的输入进入到我们的判断之内，它也很可能会为我们对判断之后的想象提供原材料。**我们不是直接判断， 而是先进行匹配，在大多数时候， 还带有想象**。而一个外在的可感知的背景提供了改变的心理暗示。

而对案件的考察顺序所导致的影响，我认为这是人类本身对于自身价值观的无意识的拟合以及代偿。**人们相信世界上的事件符合某种分布规律,但是却选择性的忽视了发生在自己身上的事件所具有的随机性与事件之间的相互独立性**. 当我们抛出十次硬币而全部得到正面， **我们多么希望下一次就是反面, 因为这样概率可预测的世界我们更有章控感， 更容易接受**. 而当下一次硬币的状态取决于你， 你则会倾向于让事件的分布变得合乎情理，而不是让这次的判决合理。说到底人们更希望为自己的世界稳定性负责而不是为一个具体的与你没有切身利益交互的案件。



这里还有一个非常危险的观点， 就是**人类根本没有办法完全控制自己的思想和大脑， 理性只是之前决策的合理化辩护手而非是一个绝对的判断者**。我们日常生活中做的更多的是， 做出看似合理但是实则随机的决策， 然后理性将这个决策合理化。
