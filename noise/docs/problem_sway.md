# 问题降级

书中提到的 人类解答难题时候的策略非常的一针见血且真实。我在阅读的时候也感觉受到了心理上的冲击： "原来我实际上是这样思考问题的吗？"

当然了心理是非常复杂的东西， 我们没有办法真正将自己的心理当成一个白盒完整的拆开并演绎。 然而他提出的这些例子我感觉无比真实。 他们都有一个共同的特点， 原始问题本身并不是一个可以通过我们可以通过简单的努力进行评估和做出判断的。比如说气候变化， 我们要回答这个问题， 首先就必须先精确地定义气候变化这个词本身， 以及对于生活感到满意这种看似非常简单的问题。 实际上， 我们没有找到一种公认的方式来评估和解决这些问题， 哪怕有， 也只能诉诸一些共识(比如说某种评估气候分布的指标达到了某个临界值我们就认为气候变化了)。 真正的问题在于， 这些问题的评估和回答所需要的**成本过高**， 首先需要拆解问题， 思考相关联的内容， 接着对那些相关联的内容进行不同维度的评分，对于一个没有经过训练的普通人， **直接将它降级为一个可以评价直觉或者一个直接可以通过直观来回答的问题**， 才是一个更划算的买卖。

也就是说问题的降级和置换之所以会发生， 就是因为人类希望可以用更少的能量消耗， 来获得大致相同的效果。如果人类对每个问题都深思熟虑， 估计早就因为能量消耗以及过多的焦虑而被自然淘汰了。这是一种普遍的策略。

承认这种策略价值的同时， 我们必须要认识到，在一些关键问题上我们不应该节省自己的脑力和判断力量。
