# 机械判断

本书提到的研究表明了在大量的研究中， 简单的机械判断普遍优于人类的判断。这令人惊讶但是也并非不可解释。

首先机械判断之所以有效就是因为真实的世界中的因素和事件之间的相关性确实满足一些统计学上面的规律， 而非纯粹的噪声和不相关。而本书在之前已经讨论了人类在一致性上有多么差劲(决策不稳定， 充满噪声). 并且在一些研究中也指出了人类的噪声比想象当中的大， 也就是说每一次决策不仅不同， 而且差异很大。 而我们可以使用数学的推导方法得出， 在噪声很大的时候， 减小噪声本身就可以显著地提高正确率。当然这也告诉我们：**人类试图用自己的复杂规则来拟合真实世界的随机噪声，然而他们却失败了**, 因为真实的世界中， 人类具有太多的 **客观无知** 并且可以考虑的维度取决于**大脑的缓存限制**， 而这些都是有明确上限的。

书中还提到一些研究， 证明了人类没有在针对七个以上的维度进行综合评估的时候， 会出现大脑缓存不足而导致的判断失误， 这也再次印证了人类的能力边界。我们不是一个全能的存在，但是我们可以打造出比我们更加全能的系统来提到我们做出决策。
