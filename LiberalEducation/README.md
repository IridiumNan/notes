# Liberal Education

> 逐段的解读查看 [parts.md](./docs/parts.md)

## 概要

- 按照心智培育本性需要老师， 不是学生的老师只有通过书. 自由教育期望的产物是“文化人”

- 不同文化的分化会导致我们没有办法直接决定自由教育的内容。在这种情况下， 我们没有办法明确学习伟大的书意味着什么。因为如果没有以某种文化作为内容， 无法分辨伟大的书。

- 民主制在理想状态下是大多数成年人都具有美德和智慧。这是一种高度理性的社会。

- 现代民主制要求权力为大众所有。但是大众并不具有治理社会的能力。 因而最终的结果并非是贤良政制--而是大众文化盛行。自由教育在这个时候就为主流的大众文化引入了发展和稳定的动能。 也为某些具有潜力的人提供精神成长的条件。

- 自由教育让人记起属人的伟大。其途径为 try to philosophize. 也就是学习伟大的书。

- 在与伟大心智交谈的过程当中， 我们会遇一个棘手的问题， 就是我们可能没有办法真正理解和评判最伟大心智留下来的思想。但是我们也必须尽自己的努力对比不同伟大心智的思想，因为伟大的心智在思想上并不统一。所以我们需要尽力做出区分， 但是由于我们自身能力的有限， 于是进入了一种矛盾的状态。

- 由于现代社会晚于那些最伟大的心智的时代， 我们经常浮现幻觉， 认为我们的认识和观点已经胜过往昔最有智慧的人。于是我们倾向于成为评判者， 然而我们并不具有评判的能力， 因为我们失去了 nomos \[礼法\] 的地基， 也就是价值的地基。

- 哲学只能是内在启蒙， 当我们理解到一些真正重要的东西的时候，我们可以超越对善恶本身的判断而达到一种纯粹的状态。这是一种理念上的超越（跟柏拉图有关？）

- 我们应当保持谦逊和大胆。 在自由教育下超越单纯的平庸。

## 主要感悟

### 精英与大众

精英批判或者说相对轻视大众文化， 是其价值表达的必须产物。也就是说， 他们一旦做出抉择，就必须要捍卫自己的价值。否则将会陷入到相对主义。

相对主义最大的问题就在于无法行动， 因为没有任何统一的价值标准进行驱动。 但是当我们思考为什么大众文化如此盛行的时候。我们应当意识到， 一旦尝试跟大众文化做切割， 就会带来大量的副作用，而虚无主义， 相对主义都会在这个过程中出现。 这对于普通大众来说并不是一个可以容易解决的问题。

现代民主制捍卫每个公民的权利，在大多数人都支持的情形下， 我们没有办法全民推行精英的价值观。一方面，它长期以来被少数的识字阶层所垄断， 在大众当中没有任何的基础，另一方面， 它没有办法立竿见影地解决人们遇到的现实问题。

但是这并非意味着所有通向更高贵和纯粹的道路都已经消失。 作者希望说的是，自由教育正在努力建立一种转化的桥梁。将一些具有潜力的大众转化为有贤能有智慧的人， 让他们重新认识到属人的伟大。

在这种情形下， 现代民主制使得简单而平庸的大众文化成为主流文化， 这是对普通人生活的尊重， 毕竟不是所有人都具有认知盈余（当然也不是所有人都愿意把认知盈余放在思考哲学上）。

同时也保留了一种流动性和连通性， 希望接触超越平庸文化的人， 在当今的时代拥有更多的途径和资源， 而自由教育希望成为其中的一种方式。

**一种价值观的捍卫者必须要保持它的高尚性**， 否则容易陷入相对主义，相对主义会让人失去稳定的生活状态。

### 伟大心智的不可接近

我认为一个人真正接近另一个人的思想是很难的， 甚至一个人接近自己的思想都是一件非常困难的事情。 我们对于自己如何生活， 为什么做出这个决定，很多时候都只能做出一种近似的猜测和假设。 我们希望基于逻辑进行分析， 但是我认为人类的行为并非完全符合逻辑。

并且书仅仅是一个伟大心智在某个时间点内的一个切片， 并非他思想的全貌。 写出来的想法可能只占整体内容的不到时分之一。更不要说从写下来到完整留存下来并且不被篡改。 另外， 文章开头提到一种群体， 也就是同时是学生的老师， 他们试图帮助后来的初学者理解伟大的心智。 问题在于， 他们对于伟大的心智的理解必定带有一定的偏差， 至于真实的偏差有多少， 我们没有办法确定。 而由于大多数人的理解能力乃至知识储备有限， 很难直接读懂伟大心智的一手作品， 绝大多数人率先接触的都是二手乃至多手的老师的解读。 这样一来， 偏差又被放大了。 这绝对不是一种危言耸听。 单单是语言不同所带来的隔阂， 已经将大多数人挡在源头之外， 他们只能够依靠下游的水来想象源头的内容。

实际上这一点我作为计算机的学生深有体会。 因为绝大多数的一手资料都是英文的文档， 标准库源代码的注释也都是英文文档。 而我身边会自己主动看这些一手的英文资料的人屈指可数。他们的学习极度依赖于中文社区的翻译。我认为在这个过程当中， 信息必然有失真或者说没有办法完全准确表达的地方。

文中一直试图将伟大的心智作为思想的源头， 或者说一种接近真理的东西， ”善“的源头。 我认为是欠妥的。

那么在这种情况下， 我们应当用什么样的态度来对待这些思想， 进而根据自己的本性来培养？

我认为应当更多地以启发自身为目的进行阅读， 思考， 总结。 而要想真正的有所感悟， 自己的经验和阅历也必须丰富。 我认为真实的实践是很重要的。 无论是对于认识自己， 认识世界， 亦或是其他方面的内容。

我这种对于原文的思考和批判也算是一种把 ”普通的意见当成极端的意见，认为它有可能出错”吧
